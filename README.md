# پلاگین PrayerChime برای Obsidian

## معرفی
پلاگین **PrayerChime** یک پلاگین سفارشی برای [Obsidian](https://obsidian.md) است که اوقات شرعی استان‌های ایران را نمایش می‌دهد. کاربران می‌توانند اطلاعات نمایش داده‌شده را شخصی‌سازی کنند و تجربه‌ای منظم و کاربرپسند داشته باشند.


## ویژگی‌ها
- **نمایش پویا اوقات شرعی**: دریافت اطلاعات اوقات شرعی از آدرس API `https://prayer.aviny.com/api` بر اساس استان انتخابی.
- **سفارشی‌سازی نمایش**: امکان انتخاب نمایش یا عدم نمایش هر یک از اطلاعات اوقات شرعی (مانند اذان صبح، ظهر، غروب آفتاب و ...).
- **انتخاب استان**: جستجو و انتخاب استان‌ها با رابط کاربری کاربرپسند.
- **رابط کاربری واکنش‌گرا**: نمایش اطلاعات با طراحی زیبا و همراه با آیکون‌های مربوطه.

## نصب
### ۱. نصب دستی
1. فایل‌های پلاگین را دانلود کنید.
2. فایل‌ها را در مسیر زیر کپی کنید:
   <br/>
   ```shell
   .obsidian/plugins/
   ```
3. نرم افزار Obsidian را ری‌استارت کرده و پلاگین را از بخش تنظیمات ← پلاگین‌های جامع(Community plugins) فعال کنید.

### ۲. نصب از بازار پلاگین‌های Obsidian
1. به تنظیمات ← پلاگین‌های جامعه(Community plugins) بروید.
2. پلاگین **PrayerChime** را جستجو کنید.
3. آن را نصب و فعال کنید.

## نحوه استفاده
### ۱. تنظیمات پلاگین
- به تنظیمات پلاگین از مسیر `Settings → PrayerChime` بروید.
- باکس جستجو را برای یافتن استان موردنظر استفاده کنید و استان خود را انتخاب کنید.
- اطلاعات قابل نمایش را شخصی‌سازی کنید:
- نمایش یا عدم نمایش اطلاعاتی مانند اذان صبح، ظهر، غروب آفتاب و ...
- تنظیمات را ذخیره کنید.

### ۲. مشاهده اوقات شرعی
- پس از فعال کردن پلاگین، اوقات شرعی در **نمای سمت راست** Obsidian نمایش داده می‌شود.
- هر اوقات شرعی با یک آیکون و برچسب توضیحی نمایش داده می‌شود.

### ۳. بروزرسانی اطلاعات
- با استفاده از دکمه **بازنشانی** در View، اطلاعات به‌روزرسانی می‌شوند.


## برنامه‌های آینده
- پشتیبانی از کشورهای دیگر.
- اضافه کردن اعلان برای زمان‌های نزدیک به نماز.
- به‌روزرسانی خودکار اوقات شرعی در نیمه‌شب.
- ترجمه به زبان‌های مختلف.

## مشارکت
